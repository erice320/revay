Page 22 - When Systems Lie Quietly

Some of the most important moments in this story are not dramatic meetings. They are failures caught in the machinery.

Notion tokens missing in isolated sessions. Model-call failures downgraded to parse errors. Disabled crons showing up as fleet problems. Transcripts failing. Salesforce field semantics that can silently return bad data if guessed. Notion API version changes from archived to in_trash. Empty records that must not be treated as evidence of absence.

These are not engineering trivia. They are the conditions under which an AI-supported executive system can either become trusted infrastructure or a confident hallucination machine.

Evan's operating doctrine, now written into the workspace, is simple: truth beats helpful-looking output. If an API call fails, report the status and raw error. If a query returns zero, say zero. If data was not retrieved in this session, mark it stale or unknown. No brief without a live search/fetch. No plausible fill-ins.

This is the moral code of the system because the business cost of false clarity is high.

The docudrama version might call this the integrity arc. The practical version is sharper: Rev.io cannot run on intelligence it cannot audit.
