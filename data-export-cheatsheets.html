Migration Data Export Guide

A simple reference to help you pull your data from your current system before your onboarding kickoff. The more you can share ahead of time, the faster we get you live.

What this is for: Your Rev.io SA will use these exports to pre-configure your new PSA environment — customers, billing codes, GL mappings, service items, and more — so you're not starting from a blank slate on day one. You don't need to be technical to do this. Just follow the steps for your system below and send us the files.

How to export from SedonaOffice

Option A — Query Builder (recommended for customer & billing data)

  1. In SedonaOffice, click Query in the top toolbar → Customer Query
  2. In the left panel, click the fields you want to include in your export
  3. Leave the middle filter frame blank to pull all records, or filter by Active status
  4. Click the green arrow to run the query
  5. Click the Export button at the bottom → save as .csv
💡 You can save your query for future use — click Save before exporting so you can re-run it anytime.

Option B — GL Query Builder (for GL codes)

  1. Click Query → GL Query Builder
  2. Add the fields you want (account number, description, type)
  3. Filter to Active = Yes to keep the list clean
  4. Run and export to CSV

Option C — Right-click export (for lists and code tables)

  1. Navigate to the relevant screen (e.g., Accounting → Bill Codes)
  2. Right-click anywhere in the data grid
  3. Select Export to Excel or Export to CSV if available
⚠️ Not all screens support right-click export. If it's not available, use the Query Builder approach instead.

How to export from e-automate

⚠️ Cloud vs. On-Premise: If you're on the hosted/cloud version, use the built-in Import/Export Utility (download an export template from within e-automate and drag it into the utility). If you're on-premise, the utility is under Tools → Import/Export, or right-click export is available on most grids. If you can't find it, ECI support can help: 1-800-989-3367.

Option A — Right-click export (quickest for most screens)

  1. Navigate to the data you want (e.g., Customers, Contracts, Equipment)
  2. Filter to Active records only before exporting
  3. Right-click anywhere in the list grid
  4. Select Export to Excel or Export to CSV
  5. Save with a descriptive filename (e.g., customers.xlsx, contracts.xlsx)

Option B — Import/Export Utility (cloud users or bulk exports)

  1. Inside e-automate, open the Import and Export Utility (look under Tools or the main menu)
  2. Download the relevant Export Template for the data type (Customers, Contracts, Items, etc.)
  3. Drag the .xlsx template file into the utility window's drop zone
  4. Click Export — the utility will populate the spreadsheet with your live data
  5. Save the completed file
💡 Export templates are pre-formatted — don't modify the column headers before dropping into the utility or it may error.

For GL Codes specifically

  1. Go to Accounting → Chart of Accounts (or GL → Accounts)
  2. Right-click the list → Export to Excel
  3. If export isn't available, ask your ECI rep to pull a GL Account List report, or a PDF printout works too
