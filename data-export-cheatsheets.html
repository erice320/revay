Data Export Guide — Migration Prep Cheat Sheets

Step-by-step instructions to export your data from your current system so we can set up Rev.io PSA exactly the way you work.

📋

SedonaOffice

by Bold Group  ·  Version 6.x instructions  ·  Estimated time: 20–30 min

Why we need this: These exports let us pre-configure your Rev.io PSA with your existing customers, billing schedules, GL codes, and service types — so your SA team isn't rebuilding your entire setup from scratch during onboarding. The goal is to get you live faster and correctly.
1

Customer List

Who you bill & their contacts
  1. In SedonaOffice, click Query in the top menu bar, then click Customer Query
  2. In the left panel (Fields to Display), click each of the following to add them:
    Customer_Number  ·  Customer_Name  ·  Customer_Type  ·  Customer_Status  ·  Bill_Address1  ·  Bill_City  ·  Bill_State  ·  Bill_Zip  ·  Bill_Contact_E_Mail  ·  Bill_Contact_Phone  ·  Site_Contact_E_Mail  ·  Site_Contact_Phone
  3. Leave the middle filter frame blank (this pulls all active customers)
  4. Click the green arrow (Run) button at the bottom
  5. Click the Export button and save as CSV
  6. Name the file customers.csv
💡 Tip: You can save this query for future use by clicking the Save button before exporting.
2

Recurring Monthly Revenue (RMR) / Billing Schedules

What each customer pays monthly
  1. Click Query → Customer Query
  2. Add these fields: Customer_Number  ·  Customer_Name  ·  System_Number  ·  System_Type  ·  RMR_Amount  ·  Billing_Cycle  ·  Next_Bill_Date  ·  Bill_Code
  3. Run the query (green arrow) and click Export → CSV
  4. Name the file rmr-billing.csv
⚠️ If you have multiple system types (alarm monitoring, access control, video, etc.) each will show as a separate row. That's expected — don't filter them out.
3

GL Codes / Chart of Accounts

For mapping revenue to the right accounts in Rev.io
  1. Click Query → GL Query Builder
  2. Add fields: GL_Account_Number  ·  GL_Account_Description  ·  Account_Type  ·  Active
  3. Filter: Set Active = Yes (to exclude old inactive codes)
  4. Run and export as CSV
  5. Name the file gl-codes.csv
📌 Alternatively: Go to Accounting → Chart of Accounts, right-click the list, and choose Export to Excel/CSV if that option appears in your version.
4

Service / Bill Codes

Your line-item billing descriptions and rates
  1. Go to Accounting → Setup → Bill Codes (or Lists → Bill Codes depending on your version)
  2. Right-click the grid of results and select Export to CSV or Export to Excel
  3. If export isn't available via right-click, use Query → Customer Query and add the Bill_Code and Bill_Code_Description fields
  4. Name the file bill-codes.csv
We're specifically looking for:
Code / ID Description Rate / Amount GL Account Mapping Taxable Y/N
5

Equipment / Systems per Site

Installed equipment at each customer location
  1. Click Query → Customer Query
  2. Expand the System category and add: System_Number  ·  System_Type  ·  System_Location  ·  Install_Date  ·  Panel_Type  ·  Monitoring_Status
  3. Also include Customer_Number and Customer_Name so we can match systems to customers
  4. Export to CSV and name it systems-equipment.csv

📤 Files to send us

  • customers.csv — full customer list with contact info
  • rmr-billing.csv — recurring billing schedules and amounts
  • gl-codes.csv — active GL account codes
  • bill-codes.csv — service/billing line item codes and rates
  • systems-equipment.csv — installed systems per site

📬 How to send your files

Zip all files into a single folder and send to your Rev.io onboarding SA. If you're unsure who your SA is, email onboarding@rev.io with subject line: [Your Company Name] — SedonaOffice Data Export. Please send prior to your kickoff call so we can review before we meet.

e-automate (ECI Solutions)

Cloud & On-Premise versions  ·  Uses Excel-based Export Utility  ·  Estimated time: 30–45 min

Why we need this: e-automate stores your customers, contracts, service items, and equipment in a structured database. These exports let us mirror that structure in Rev.io PSA — so billing codes, customer accounts, and recurring contracts are already in place when you log in for the first time.
⚠️ Before you start: e-automate uses a built-in Data Import/Export Utility (also called the DataImportExport tool). If you're on the Cloud/Hosted version, you access Export Templates from within e-automate. If you're On-Premise, the utility is typically found under Tools → Import/Export or as a standalone Excel file provided by ECI. If you can't find it, call ECI support at 1-800-989-3367.
1

Customer List

Company names, addresses, contacts, billing info
  1. In e-automate, go to Customers in the left navigation
  2. Set the status filter to Active only
  3. Right-click anywhere in the customer list grid → Export to Excel (or look for a Print/Export button in the toolbar)
  4. Cloud users: Use the Data Import/Export Utility → download the Customers Export template → drag it into the utility window → click Export
  5. Save the output as customers.xlsx or customers.csv
Columns we need:
Customer Number Company Name Billing Address Primary Contact Name Email Phone Credit Hold Y/N Customer Type
2

Equipment / Devices per Customer

Machines under service contract at each site
  1. Go to Equipment in the left navigation
  2. Filter to show Active equipment only
  3. Right-click the grid → Export to Excel, OR use the Import/Export Utility with the Equipment Export template
  4. Save as equipment.xlsx
Columns we need:
Equipment ID / Serial Number Customer Number Model / Item Code Location / Description Install Date Contract Number Contract Type
3

Contracts / Service Agreements

Recurring billing contracts and rates
  1. Go to Contracts in the left navigation
  2. Filter to Active contracts
  3. Use the Import/Export Utility with the Contracts Export template, OR right-click the grid and select Export to Excel
  4. Save as contracts.xlsx
Columns we need:
Contract Number Customer Number Contract Type Monthly Billing Amount Start Date End / Renewal Date Billing Frequency GL Account
⚠️ If you have separate billing codes per contract line item, include the Contract Items export as well (separate sheet or file). This maps specific billing lines to GL codes.
4

Items / Service Codes

Your product/service catalog — labor rates, part codes, supply items
  1. Go to Inventory → Items (or Lists → Items depending on version)
  2. Use the Import/Export Utility with the Items Export template, OR right-click the item grid → Export to Excel
  3. Filter to Active items only to keep the list manageable
  4. Save as items.xlsx
Columns we need:
Item Code Description Item Type Cost / Price GL Account Taxable Y/N Unit of Measure
5

GL Codes / Chart of Accounts

Revenue mapping for billing
  1. Go to Accounting → Chart of Accounts (or GL → Accounts)
  2. Right-click the list and select Export to Excel
  3. If unavailable: use the Import/Export Utility or ask your ECI account rep to pull a GL Account List report
  4. Save as gl-codes.xlsx
💡 Even a printed PDF of your Chart of Accounts is helpful if export isn't available. We just need the code numbers and descriptions.

📤 Files to send us

  • customers.xlsx — full active customer list with contacts
  • equipment.xlsx — active devices/machines per customer
  • contracts.xlsx — active service contracts and billing amounts
  • items.xlsx — your product/service item catalog
  • gl-codes.xlsx — chart of accounts / GL code list

📬 How to send your files

Zip all files into a single folder and send to your Rev.io onboarding SA. If you're unsure who your SA is, email onboarding@rev.io with subject line: [Your Company Name] — e-automate Data Export. Please send prior to your kickoff call so we can review before we meet.

🤝 Need help with the export? Your ECI account rep or ECI support (1-800-989-3367) can assist with the Import/Export Utility. For Cloud customers, the Export Templates are also documented at Help → e-automate Online Help → Data Import/Export inside the application.
