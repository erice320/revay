ICP And Fit

ICP should define where Rev.io can win, implement, retain, and create advocates now.

Rev.io should use one shared ICP quality bar and three segment lanes. The shared bar is recurring revenue spine or clear workflow replacement pain, operational complexity that Rev.io can monetize, an attach or expansion path, implementation readiness before close, decision-maker urgency, and usable data rails for automation. The lanes are CSP/Billing-led providers, security and field-service PSA-led operators, and MSP/IT services workflow-led operators. The anti-ICP is not a bad industry label; it is an account with weak economic floor, no attach path, unsupported custom workflow needs, poor implementation readiness, low data readiness, and no executive urgency.
Scale

Proof-backed replacement

Named incumbent, clear pain, decision access, implementation readiness, and reference path.

Fix

Demand with friction

Good account, real urgency, but onboarding/product/support burden needs an explicit commitment.

Narrow

Conditional fit

Win only if roadmap, migration, contract timing, or champion readiness lines up.

Stop

Unsafe promise

No business issue, no buyer control, weak fit, or predictable implementation pain.

Anti-ICP: A low-MRR, one-product, no-attach-path prospect with no clear transaction/workflow complexity, weak implementation ownership, messy or unavailable data, unsupported custom PSA/integration requirements, no decision-maker urgency, or a known contract/timing blocker. Sales should be able to walk away when these are present, even if the logo looks attractive.

ELT Decisions

The deck should force decisions, not just alignment.

1. What should GTM scale?

Which ICP / incumbent / pain combinations have enough proof to increase demand and sales focus?

2. What needs a fix before more demand?

Which product, onboarding, or support gaps make current demand expensive or unsafe?

3. What should be narrowed?

Which accounts need explicit readiness gates, roadmap commitments, or contract-timing nurture?

4. What should stop?

Which claims, campaigns, or deal profiles outpace current delivery proof?

Recommended operating cadence: weekly retained-revenue conversion review covering source -> opportunity -> win/loss -> implementation readiness -> go-live -> support friction -> renewal/fan signal.
